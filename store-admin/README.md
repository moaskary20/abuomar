# متجري — لوحة تحكم FilamentPHP

لوحة تحكم عربية كاملة لإدارة المتجر باستخدام **Laravel 12** و **FilamentPHP 5**.

## التشغيل

```bash
cd store-admin
composer install
cp .env.example .env   # إن لم يكن موجوداً
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

ثم افتح: [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)

## بيانات الدخول

| الحقل | القيمة |
|--------|--------|
| البريد | `admin@store.test` |
| كلمة المرور | `password` |

## ما تتضمنه اللوحة

- **المنتجات**: الأقسام، العلامات التجارية، المنتجات (أسعار، كميات، صور، باركود)
- **المخزون**: حركات الإضافة/الصرف/التعديل، الموردون
- **المبيعات**: العملاء، الطلبات مع عناصر الطلب
- **التسويق**: الكوبونات، التقييمات
- **الإعدادات**: طرق الشحن، إعدادات المتجر
- **لوحة الرئيسية**: إحصائيات وأحدث الطلبات

الواجهة باللغة العربية مع دعم RTL تلقائياً.
